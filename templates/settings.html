Recommended: free auto “From” address (Resend)

Emails come from Windstar Tahiti Price Tracker <onboarding@resend.dev> and go to {{ alert_email or 'your Gmail' }}.

  1. Create a free account at resend.com (use {{ alert_email or 'your email address' }}).
  2. Open API Keys → Create API Key → copy it.
  3. Edit .env: 
    EMAIL_PROVIDER=resend
RESEND_API_KEY=re_your_key_here
EMAIL_FROM=Windstar Tahiti Price Tracker <onboarding@resend.dev>
ALERT_EMAIL=you@example.com
DEPARTURE_DATE=2027-05-20
  4. Restart the app, then click Send test email below.

Note: with Resend’s free test sender, you can usually only email the address you signed up with until you add your own domain.

Optional: send via Gmail SMTP instead

EMAIL_PROVIDER=smtp
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=you@example.com
SMTP_PASSWORD=your-gmail-app-password
ALERT_EMAIL=you@example.com

Site logins (Perx + ID90)

Session file: {{ session_path }} {% if session_ok %} Saved {% else %} Not saved yet {% endif %}

Perx needs login to show rates. ID90 usually shows the fare without login (we already track it at $6,216).

Same style as Resend — put credentials in .env

PERX_USERNAME=your_perx_username
PERX_PASSWORD=your_perx_password
ID90_EMAIL=your@email.com
ID90_PASSWORD=your_id90_password

Then run:

cd ~/cruise-price-tracker
source .venv/bin/activate
python scripts/login_sites.py

Or interactive browser (type passwords in the window, not in chat):

python scripts/login_sites.py --interactive

How price detection works

  • Opens the booking URL in a headless browser (Playwright).
  • Auto-detects dollar amounts that look like cruise fares.
  • If auto-detect fails, open the page in Chrome → right-click the price → Inspect → copy a CSS selector → paste it on the cruise.
  • Emails fire only when the new price is lower than the last recorded price.
